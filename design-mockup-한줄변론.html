FEATURE OVERVIEW
한줄 변론 기능
디자인 시안
투표할 때 "왜 이걸 골랐는지" 한줄 이유를 남기는 기능입니다. 투표에 맥락을 더하고, 사용자 체류시간을 늘리며, 커뮤니티 인터랙션을 만듭니다.
DESIGN A
상품 카드 내 변론 표시
각 상품 카드 하단에 해당 상품을 픽한 유저들의 한줄 변론이 표시됩니다. 베스트 변론이 상단에 고정됩니다.
DESIGN B
투표 시 변론 입력 플로우
상품 선택 후 하단 투표 바에서 한줄 변론을 입력합니다. 선택사항이지만 자연스럽게 유도합니다.
DESIGN C
전체 변론 탭 뷰
상품 그리드 아래에 전체 변론을 모아보는 탭 섹션입니다. 최신순/공감순 정렬과 상품별 필터를 지원합니다.
DESIGN D
통합 시안 (최종 추천)
A+B+C를 결합한 실제 배틀 상세 페이지의 전체 플로우입니다.
